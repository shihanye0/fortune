# Spec 031：紫微斗数模块（含每日推送"紫微流日"卡）

> 2026-11-14。算法 port 自 iztro（MIT）安星诀，口径确认参照 Renhuai123/ziwei-doushu（MIT）。

## 口径（主流排盘口径，金标准 54/54 与 iztro 逐字段一致）

- 农历正月初一换年（yearDivide='normal'；紫微用农历年，与八字立春口径不同，页面与解读均注明）
- 闰月前 15 天归本月、16 起（含 16）归下月（fixLeap=true）
- 晚子时（23:00-24:00）归当日子时（从 Renhuai123 主流口径；iztro 默认 dayDivide='forward' 会进次日，未采用）
- 亮度表 = iztro STARS_INFO（寅起宫位索引）；庚年四化=阳武阴同（iztro 默认）
- 播单解释框架：确定性排盘在前、LLM 只解释；夏令时只提示不自动调时（dst_cn.py，36 行表与源仓逐条对齐）
