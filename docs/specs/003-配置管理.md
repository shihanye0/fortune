# Spec 003: 配置管理

> 模块：基础设施 | 优先级：P0 | 预计：0.5 天

## 功能描述

统一管理项目配置，通过环境变量读取敏感信息，支持 .env 文件。

## 配置项

| 配置项 | 说明 | 示例 |
|--------|------|------|
| DATABASE_URL | 数据库连接 | mysql+pymysql://user:pass@localhost:3306/fortune |
| DEEPSEEK_API_KEY | DeepSeek 服务器默认 API Key | sk-... |
| DEEPSEEK_BASE_URL | LLM API 地址（服务器默认） | https://api.deepseek.com |
| LLM_ALLOWED_HOSTS | 可被个人 LLM 配置访问的 HTTPS 主机白名单 | api.deepseek.com |
| LLM_CREDENTIAL_ENCRYPTION_KEY | 个人 API Key 的 Fernet 加密密钥 | base64-encoded-fernet-key |
| SMTP_HOST | QQ 邮箱 SMTP | smtp.qq.com |
| SMTP_PORT | SMTP 端口 | 465 |
| SMTP_USER | 发件邮箱 | your-qq@qq.com |
| SMTP_PASSWORD | SMTP 授权码 | xxx |
| JWT_SECRET | JWT 签名密钥 | random-secret-key |
| JWT_EXPIRE_HOURS | Token 过期时间 | 24 |
| INTERNAL_API_KEY | GitHub Actions 调用内部推送接口的共享密钥 | long-random-secret |
| APP_PORT | 服务端口 | 8000 |
| APP_ENV | 运行环境 | development/production |

## 验收标准

```
Scenario: 环境变量正常读取
  Given .env 文件配置正确
  When  启动应用
  Then  所有配置项应正确加载

Scenario: 缺少必填配置时报错
  Given DEEPSEEK_API_KEY 未配置
  When  启动应用
  Then  应报错提示缺少配置项
```

## 技术要点

- 使用 pydantic-settings 管理配置
- .env 文件不提交 Git，.env.example 提交
- 敏感配置启动时校验
- 个人 API Key 只以加密密文落库；不要在日志、测试输出或文档中记录真实密钥
- `INTERNAL_API_KEY` 与 GitHub Actions Secret 必须保持一致，否则每日推送会被拒绝
